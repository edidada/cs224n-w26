# A4 LLM Evals：实现进度与验收边界

来源为仓库导入的 Stanford CS224n Winter 2026 官方 A4 starter；该仓库是归档镜像，不是官方 Git fork。

本分支目前补全 GSM8K 标准 A/B、改进提示 A 的全 100 题评测入口。官方标准提示与提取器保留；使用十进制数值比较，无法解析或非有限值计错，分母包含全部题目。逐次保存问题、提示、原始响应、令牌与费用、预期答案和判定，异常会中止并保留已完成记录。输出独占创建，已有记录不会被覆盖；暂不支持断点续跑，不能删除记录盲目重试以免重复计费。

Alpaca 裁判提示和严格末行标签解析已实现，矛盾、重复或缺失标签返回无偏好。数据路径相对源码定位。标签解析仍把真平局与无效输出合并到官方无偏好标签；后续聚合必须另外记录解析状态，不得把无效输出算作有效平局。

尚未完成：Alpaca E/F/Z 全量调用与聚合、人工核对 5 条及真实分歧、长度直方图；GSM8K 实际分数与比较图、改进是否成立；G/H/I 合成密码红队实验及失败策略。没有真实 API 结果，没有宣称提示词改善分数。

真实运行需要用户提供的 GCP 项目、ADC 身份、STUDENT_EMAIL 和明确费用预算。本轮未调用 Vertex，未产生云端评测费用。官方客户端保持原样。当前仅源码静态检查，不构成实验验收；独立 A4 工作流与离线协议验证仍待补全。禁止根据客户端秘密生成逻辑伪造红队成功。
